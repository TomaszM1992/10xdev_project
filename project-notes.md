# TODO App - MVP

### The problem
Managing daily agenda priorities is tricky which results in a lot of todo tasks being dismissed instead of completed when it was initially planned

### MVP
- Create tasks with assigned date, priority (1-3) and how much time is needed to complete them
- prioritizing tasks for a given date based on priority
- tasks can be assigned with tags (max 5 tags per task) and filtered by those tags
- Review, edit, delete, complete, dismiss tasks. 
- Calendar view of agenda
- Basic user accounts and authentication

### non-MVP
- Automated AI-based process of task prioritization and planning based on date and task size
- Support for pomodoro when planning daily agenda
- importing tasks from other TODO apps
- 3rd party Auth (google, facebook)
- mobile App
- 3rd party calendar integration (google, microsoft)
- habits tracking
- account removal flow
- landing page
- Completed tasks archived, not polluting Tasks section
- Creation date

### success criteria
- 60% of tasks planned are being completed instead of being dismissed
